# CLAUDE.md (workspace)

Two apps: `template-back` and `template-front`. Each has its own CLAUDE.md with the real rules. Read the one for the app you change, plus its PROGRESS.md.

- Envelope: `{success,message,statusCode,data,error}`. Pagination: `{data, meta:{itemsPerPage,totalItems,currentPage,totalPages}}`. Tokens live in HttpOnly cookies only.
- Roles are fixed: SUPERADMIN (env-defined) and SPARTAN. There is no tenant, company or permission table.
- A new feature is a vertical slice in both apps. Copy `example-item` (back) and `example-items` (front). Project-scoped data carries `projectId` explicitly.
- Ids are UUIDv7 strings generated by PostgreSQL 18 (never numbers). The schema changes only through numbered SQL migrations (`template-back` CLAUDE.md, "Database"); a new or changed entity needs one.
- Slow or side-effecting work is a job run by a worker through an engine in `template-back/src/engines/<id>/`. Engine developers change only their own folder (`src/engines/CLAUDE.md`); never weaken the dependency-cruiser / ESLint / CODEOWNERS / CI walls around it.
- Never commit `.env.*` files with real secrets.
